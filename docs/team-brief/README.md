# Team briefs (historical)

Original specs and notes from the three builders' branches, kept for the business context, acceptance
criteria and demo scripts. **They describe the old starter-pack contract (`ShopperSession`, `FeatureProps`,
`DataProvider`, `src/app/`) and the original standalone Fit Studio, which are superseded.** The merged app
uses the contract in `src/shared/` — see the root `README.md` and `CLAUDE.md`. Where a spec's behavior
matters (try-on privacy, offer rules, size/fit rules) the merged code implements it on the new contract.
